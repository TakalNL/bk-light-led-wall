# Private local archives

`private/` holds compressed completed captures, reference checkouts and selected
build/validation artifacts. It is ignored by Git and is not a distributable asset
directory. SHA-256 manifests accompany the ZIP files.

Public historical reports live in [docs/archive](../docs/archive/README.md).
See [recovery instructions](../docs/development.md#private-archives) before
extracting files. Runtime panel preferences live separately in `.state/`.
