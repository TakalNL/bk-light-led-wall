# Remaining release work

The current application is a working Windows source prototype with three games.
The initial user is another buyer of this exact B.K. Light panel.

1. Build a distributable Windows application and test installation on a second
   machine without the development environment or a saved panel identifier.
2. Provide first-use panel discovery, selection and a visual identify pattern.
   Reject unknown profiles clearly before uploading content.
3. Verify another purchaser's unit, recording model/type/version information
   without publishing unique device identifiers.
4. Exercise unavailable/busy devices, power-cycle recovery and repeated sessions
   on a clean host. Never retry ambiguous partial uploads automatically.
5. Choose the application license and assemble dependency/asset notices before
   publishing a distributable release. Keep unlicensed downloaded test art out.
6. Exercise LED Wall's image/GIF playback and layout controls on further hardware;
   measure visible seam timing and recovery with two panels during gameplay.

Brightness, hardware orientation commands, firmware updates and hardware refresh synchronization
remain outside the validated release scope. The Windows profile remains opt-in;
further transport experiments need reproducible evidence before integration.

The public chunk-size proposal has been submitted upstream. A wider hardware
report remains a draft. No additional performance PR is planned from the current
results. Original scope and decision history are in the
[archived product plan](archive/PRODUCT_PLAN.md) and [original brief](archive/project.md).
