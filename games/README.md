Run launchers from this checkout's Windows environment. Only one game can hold
an active panel connection. PC-only preview works without Bluetooth.

All games share their [desktop shell and transport](common/README.md), panel
settings, 10-fps default and optional Windows 12-fps profile. Choose the output
profile before connecting. The profile changes output pacing, not game speed.
See the [root README](../README.md) for installation and [validation](../docs/validation.md)
for hardware results.
